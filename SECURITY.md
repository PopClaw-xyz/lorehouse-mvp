# Security

Ranger Map is a developer preview: a reference server meant to be read and run
locally, not a hardened deployment.

## Report a suspected vulnerability

Email **security@popclaw.xyz**. Use that address rather than a general contact
route.

Do not put vulnerability details in an issue or a pull request. Who can read
those today is not the point — a report that arrives in the open cannot be
taken back. Do not send credentials, signing keys, session tokens, private
messages, or an unredacted database.

A useful initial report includes the affected version or commit, a short description of the impact, and minimal reproduction steps using synthetic data. Arrange a private transfer with the maintainer if additional sensitive evidence is needed.

Fix availability and affected versions will be assessed for each report; this Developer Preview does not promise a response time or long-term support for every preview build.
